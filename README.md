# 🥛 Zibbo App Hider

A local encrypted vault for hiding and protecting files and folders.

Zibbo started as a simple Windows file hider and evolved into a more complete encrypted vault using Python and PySide6.

## ✨ Features

* 🔐 AES-GCM encryption
* 🔑 Password protection with scrypt
* 📁 File and folder encryption
* 📦 Chunk-based encryption for large files
* 🗃️ Encrypted vault metadata
* 🛡️ Safe folder extraction
* ⚡ Background encryption/decryption
* 🖥️ Modern PySide6 interface
* 🌙 Dark and light themes
* 🖱️ Drag & drop support

## ⚠️ Important

This project is still under development and **may contain bugs or security issues**.

Use it at your own risk and **always keep backups of important files**.

Especially be careful when:

* Encrypting important files
* Decrypting/restoring files
* Changing your password
* Moving or deleting vault data
* Testing the application on real data

I recommend testing Zibbo with copies of your files first.

This project has **not been professionally security audited**.
